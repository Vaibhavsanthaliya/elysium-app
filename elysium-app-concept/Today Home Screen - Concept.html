What's actually wrong

Nothing is broken. It just doesn't announce itself as the room you walked into.

No threshold
EA-167A removed the date header to kill redundancy — correct — but it took the front-door identity with it. Temple opens with an eyebrow, a DM Sans heading, a Spectral italic accent noun, and a state line. Today opens with a bordered box labelled INTENTIONS. One feels like arrival; the other feels like a settings group.
Boxes, not rhythm
Three identical bordered card-blocks stacked on the floor. The design system explicitly flags the card wrapper as a divergence — the prototype wants naked separator-led rows. The boxes are what make it read as a utility page.
Mono labels carry the hierarchy
Section identity lives in tiny uppercase mono eyebrows (INTENTIONS / OPEN). That's the language of metadata, not of a primary surface. The Spectral italic voice — the one that makes Elysium feel composed — is absent.
Flat light
The ambient temple gradient and the warm-hairline restraint that give every other screen depth aren't doing any work here. It's evenly grey.

Direction A · The Threshold

A

The Threshold

Give Today the front door it lost. Then get out of the way.

Hierarchy
Masthead → intentions (hero) → yesterday's echo → open (quiet) → footer. The page reads top-down like every other Elysium screen, with intentions as the clear centre of gravity.
Layout
No containers. Content sits directly on the obsidian floor, separated only by warm 8%-hairlines. Generous vertical rhythm does the structuring that boxes used to.
Treatment
Restores the canonical masthead: mono date eyebrow, DM Sans 30px heading, Spectral italic accent on "intentions" — exactly parallel to "Today's temple". Ambient temple light at the crown.
Intentions
Naked separator-led rows — the prototype's intended task pattern. 20px bronze check (kept = filled bronze, never green), 15px DM Sans, quiet release ✕. Section label is Spectral italic "Placed", with a bare 02 / 03 count as soft meta — a capacity hint, not a score.
Open rows
Demoted to a quiet lower zone under a Spectral italic "Open" label with the period word as right-meta ("Morning"). Mono state word per row (Open / Held), no chevron emphasis. Reads as orientation, not a checklist.
Carryover
A single gentle echo between intentions and open: a mono "Yesterday left" label, the phrase in Spectral italic, and two plain text actions. Inline, never a box, never guilt.

What stays

  • All EA-166 behaviour: add, keep, release, carryover, time-aware open rows
  • Bronze check, line-through kept state
  • Footer line, empty-state voice

What's removed

  • The three bordered .today-plan-block card surfaces
  • Mono INTENTIONS / OPEN block eyebrows
  • The flat, container-led grey

Risk

Without containers, discipline carries everything. If the rhythm or hairline weights drift, it can feel under-structured rather than quiet. Mitigated by the masthead anchoring the top and the Spectral labels giving each zone a clear voice.

Direction B · The Workbench

B

The Workbench

Make Today a physical surface — the bench where the day's work is laid out.

Hierarchy
Short orientation → intentions on the bench → open tools below. The bench is the object; everything else is the room around it.
Layout
One warm --bg-soft surface holds the intentions — a single quiet "bench" that floats on the floor with the page as its margin. Open items sit outside the bench, on the floor, as the tools you reach for.
Treatment
Lighter masthead — a single Spectral-accented line ("A quiet day. Begin.") instead of a full heading stack. The bench gives the page one calm centre of mass.
Intentions
Separator rows inside the bench. Same bronze check and release as A — the warmth of the bench surface is the only added structure.
Open rows
Become tools: each gets a 34px medallion drawn from the existing glyph library (Care's bowl, Chronicle's rings, Sleep's crescent). Two-line cell — name + mono state. Reads as "the instruments for this hour".
Carryover
A soft dashed inset within the bench — yesterday's words tucked into the corner of the surface, not a separate event.

What stays

  • All EA-166 behaviour and states
  • Time-aware open set (Care / Chronicle / Sleep / Focus)
  • Glyph library reused verbatim — no new icons

What's removed

  • The OPEN bordered block (becomes the tools strip)
  • Duplicate mono block eyebrows
  • Plain stacked-box monotony

Risk

Two real hazards. (1) Medallions on open rows borrow Temple's exact card vocabulary — risks the two home surfaces looking like duplicates. (2) One large warm surface can tip toward "dashboard panel" if it grows. Best if the bench stays small and the medallions read as restrained, not decorative.

Direction C · First Light

C

First Light

Let the screen quietly know what hour it is — without ever measuring it.

Hierarchy
Time-of-day orientation → intentions → "the hour holds" → footer. Same bones as A, but the top is a felt atmosphere rather than a titled masthead.
Layout
Naked rows like A. The difference is purely at the crown: the ambient temple light and the orientation line shift with the existing period buckets (first-light / morning / midday / evening / night) already computed in code.
Treatment
The orientation is a large Spectral italic state sentence — "Two intentions placed. The morning is still yours." A row of three small bronze dots marks the arc of the day. Not a progress device — it never fills, never scores, never compares.
Intentions
Identical to A — naked rows, bronze check, Spectral "Placed" label.
Open rows
Labelled "The hour holds" — the open set framed as what this part of the day naturally contains, with the period word as meta.
Carryover
Same gentle echo as A, shown only on the first open after a one-day gap.

What stays

  • All EA-166 behaviour and states
  • Existing period-bucket logic (no new state)
  • The naked-row system from Direction A

What's removed

  • Bordered blocks and mono block eyebrows
  • Static, time-blind framing

Risk

This is the line the brief draws in red. "The morning is still yours" and a day-arc of dots flirt with over-poetic and could be misread as a progress indicator — both explicitly unwanted. Defensible only if the copy stays plain and the dots are unmistakably ambient. Higher craft cost, narrower margin for error.

VRecommendation
Build Direction A

The Threshold

It resolves the single biggest reason Today doesn't feel like the front door — the missing masthead — by restoring the exact identity pattern every other screen already uses. The user instantly recognises where they are.

It also settles a debt the design system itself flags: tasks were always meant to be naked separator-led rows, not card-wrapped. Direction A makes Today the screen that finally honours that, which pulls the rest of the app toward the prototype rather than away from it.

And it is the lowest-risk to ship: mostly CSS, a small markup reshuffle, and a few lines of render copy. No new state, no new functionality, no constitutional grey area. Direction B's bench is the strong second — its "workbench" framing can be borrowed as A's orientation wording — but its medallions risk mirroring Temple. Direction C is worth keeping as a future atmosphere layer, not the first move.

CSS / component strategy

Reuse, don't invent

  • Masthead = copy of the proven .care-eyebrow / .care-title / .care-blurb spec — same sizes, same .ital accent.
  • Section labels = the existing .care-section-label Spectral-italic 17px pattern.
  • Naked rows already exist for #pane-care .task-item (EA-33) — mirror those separator rules exactly.
  • Only one new token need: none. All values exist (--separator-warm, --bronze, radii).

Do not touch

  • js/domains/today-plan.js — rollover, carryover, intention CRUD logic
  • state.today shape, migration, or STORAGE_KEY
  • Any element id bound in main.js delegation
  • Care cycle logic, Chronicle, Sleep, Temple, all modals
  • The 4-tab nav order (Today · Care · Temple · Settings)
§19B compliance — how A stays inside the line

Every change is presentation. Intentions remain 1–3 user-authored, kept/not-kept, releasable. Carryover is the same one-day quiet echo. The "02 / 03" is a capacity hint, not a completion ratio — no "X of Y done", no percentage, no streak. The sub-line is qualitative state assembled from today only. No history, no trajectory, no app-generated suggestion. Passes the Six Tests as cleanly as the current screen does — it simply says it in Elysium's own voice.

VIIRisks · what to avoid in the build

Craft hazards

  • Under-structuring. Without boxes, the masthead and Spectral labels must carry the hierarchy. If hairline weights or vertical rhythm slip, it reads as unfinished, not quiet. Hold the 8% separator and generous spacing.
  • Heading redundancy. The eyebrow shows the date; the heading must not also say "Today". Keep "Today's intentions" as the only instance.
  • Sub-line creep. The qualitative state line must never quantify. "Two placed. Morning care is still open." — yes. "67% kept" — never.

Constitutional traps

  • Don't let "02 / 03" acquire "of" / "completed" / a progress bar — it must stay a bare capacity glyph.
  • No medallion progress arcs on Today (those live on Temple) — avoids both duplication and a score reading.
  • No carryover counts, no "carried 3×", no day-to-day comparison.
  • Resist adding Focus/Sleep affordances beyond the existing time-aware open set — scope is visual only.

Today should feel like crossing a threshold into a quiet, well-kept room — the same room every time, that holds only what you placed in it.
