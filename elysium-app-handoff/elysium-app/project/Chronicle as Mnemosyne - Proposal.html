EA-202 · Design Direction · Proposal Only

Chronicle as Mnemosyne

Make memory the form, not the label. The conversion is nearly done at the surface — the work left is to protect the shape that already remembers, and to retire the two places that still speak like a notes app.

Surface · Chronicle Patron · Mnemosyne Gates · Utility + Form Mode · Copy + micro-visual
Recommended direction01

EA-196 already moved the Chronicle labels into Mnemosyne's register — MNEMOSYNE eyebrow, Remember, Search what remains, Remembered. So the temptation now is to add more myth. Resist it. The Form Gate is mostly passed already — but by structure, not vocabulary, and that structure is invisible until you name it.

Three gestures already make Chronicle behave like memory rather than a log: you meet what remains before you write (the surface opens to resurfaced lines; the writing field sits beneath); old entries dim with age (the Drift's four-step fade); and the past returns unbidden (the Well surfaces one line by date-math, never by query). That is Mnemosyne. Keep it, and say so.

The proposal is therefore deliberately small: one firm copy change (the save confirmation, the last place the surface says Saved like a file), one tied micro-visual, and two optional refinements you can take or leave. Everything else is a considered hold — restraint is the recommendation, and the constitution agrees.

Where it already feels like her03
i
Reading-first hierarchy
The write surface renders resurfaced lines, the Well, and the river of past entries above the textarea — the code even calls writing the "secondary motion." You return to what remains before you leave anything new. That ordering is the single most Mnemosyne decision in the surface.
ii
Memory dims with age
Drift entries fade across four opacity steps — vivid, is-quiet, is-quieter, is-faint — keyed to days elapsed, not list position. Recollection gauzing over time, rendered as atmosphere. This is the felt-not-read organ of the surface. §4 · §8.1
iii
The past returns unbidden
The Well surfaces exactly one prior line, chosen by anniversary / cycle / deep-time math — never ranked, never searched, never tappable into a "view all." Memory comes to you; you do not retrieve it. §11 · §15.3
iv
The labels already speak memory
Nothing has been left here yet. · Nothing answered. · What was left here remains. — leaving, calling, and remaining are already the verbs. Return is a sanctioned room verb. §1.7
Where it still feels generic04
1
The save confirmation
Saved · 9:42 PM  is the one place the surface drops back into productivity-app register. Saved belongs to documents and drafts; in Mnemosyne's room, a written line is left, not filed. This is the proposal's one firm change.
2
A stack of water metaphors
Two images are visible at once — From the well and The river. The well is Mnemosyne's own spring; the river dilutes that single image into a second, competing one. Worth resolving — but optional, not load-bearing.
3
The Write toggle is a neutral verb
Write is plain utility while everything around it speaks memory. Defensible to keep (clarity), but if you want the pair to rhyme, Leave / Remember maps cleanly to leaving-and-returning. Low confidence — your call.
4
A spelled-out number in a label
The resurface label Seven days ago carries a count, in soft tension with the no-number rule for qualitative labels. A week ago removes it. Minor cleanup. §11.6

Visual & layout06

No new components, no icons, no parchment, no columns. Everything below uses the existing system — DM Sans, Spectral italic, JetBrains Mono, bronze, warm separators. The surface is already visually strong; the goal is to preserve its form and make one tiny change land.

  • Promote the save line to bronze. The single tied visual move: render .chronicle-status in var(--bronze) instead of muted, keeping mono / 10px / 0.12em / uppercase. It then reads as a quiet patron meta-mark — "Left · 9:42 PM" — rather than an app toast.
  • Protect the reading-first order. The textarea must stay beneath what-remains. This is the load-bearing Mnemosyne gesture; never let a future "compose-first" instinct float it to the top.
  • Keep the four-step Drift fade. The vivid → faint opacity ladder is the felt memory organ. Leave the thresholds alone; do not flatten or "tidy" it.
  • Leave the prompt card's dashed border as-is. It already reads as an inscription-in-waiting. Adding ornament here would be decoration, not form.
  • Optional, if the river is renamed: nothing else moves — same Spectral italic 17px header treatment, same position above the Drift.
What not to change07
  • Search behavior — literal substring only; reverse-chronological; no ranking, no semantic match. §15.4A
  • Resurfacing logic — one entry at a time, deterministic, non-tappable, silent on absence. Do not touch the Well / Drift / resurfaced selection. §11 · §15.3
  • The four permitted Chronicle screens — write, Drift, the Well, archive/search. No fifth surface, no "memory" tab, no timeline. §15.5 · §20.15
  • No new state — no tags, categories, counts, word counts, stats, mood, sentiment, summaries, AI, or pattern inference. §9 · §10 · §20
  • Storage spine — state shape, DEFAULT_DATA, migrateState, STORAGE_KEY, Supabase schema, IndexedDB all untouched.
  • No Greek exposition — never explain Mnemosyne in copy. She is felt through form, never narrated.
